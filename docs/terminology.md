# Pixel Terminology Standard

One term per concept, everywhere in the product.

| Term | Meaning | Never use |
| --- | --- | --- |
| World | Major curriculum grouping (e.g. Computer Foundations) | "level", "chapter", "course" |
| Level | Progression unit inside a world (1–100) | "lesson", "stage", "module" |
| Lesson | Learning unit inside a level | "level", "class", "module" |
| Topic / Skill | Concept or capability being learned | "subject", "tag" (user-facing) |
| Knowledge Practice | Conceptual questions and understanding checks (MCQ, reasoning) | "Coding Practice", "quiz mode" |
| Coding Practice | Real programming tasks — only when execution exists | used for MCQs |
| Revision | Deliberate revisit of previously learned material | "review mode" (button copy may say Review Lesson) |
| Completion | Finished a learning activity | "mastery" |
| Mastery | Evidence of understanding (accuracy, recency, consistency) | "completion", "progress" |
| Current | Where the learner is right now | "active level" |
| Locked | Prerequisites not yet met (not permanent) | "unavailable forever" |
| Coming Soon | Planned, not broken | "disabled", "broken" |

## Status labels (title case, exact)
Not Started · Attempted · Solved · Needs Review · Mastered · In Progress · Completed · Locked · Available · Current · Coming Soon

## Button verbs (direct action)
Start First Lesson · Start Lesson · Continue Lesson · Review Lesson · Open Curriculum · View Progress · Try Again · Submit Answer · Next Question · Expand World · Collapse World · Reset Local Progress

## Product name
"Pixel" everywhere user-facing. "IT QUEST" only in internal/historical documentation.

## Rules
- Never imply one correct answer = mastery, or reading = mastery.
- Never show "Not Started" alongside non-zero progress.
- Empty states state what is empty, why, and the next action.
- Error copy explains the problem without technical internals; retry labels say "Retry".
